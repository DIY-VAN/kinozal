# Кинозал

Совместный просмотр видео с друзьями в браузере:

- **синхронный плеер** — пауза, перемотка и скорость общие на всю комнату, отставание подтягивается автоматически;
- **источники**: YouTube, Rutube, прямые ссылки на `.mp4` / `.webm` / `.m3u8`, или **свой файл** (каждый открывает у себя одинаковое видео, сервер держит всех на одной секунде);
- **текстовый чат** с историей последних 150 сообщений;
- **голосовой чат** (WebRTC, без установки программ): выкл. микрофона, громкость каждого участника, подсветка того, кто говорит;
- реакции-эмодзи поверх экрана, горячие клавиши: `Пробел` — пауза, `←` / `→` — ±10 секунд, `F` — во весь экран.

Комнаты создаются по ссылке вида `https://ваш-сайт/r/kometa-luna-418`. Регистрация не нужна.

## Вариант 1. Бесплатный хостинг на Render (≈10 минут)

Понадобятся бесплатные аккаунты на GitHub и Render.

1. **Загрузите проект на GitHub.**
   Зайдите на <https://github.com/new>, назовите репозиторий, например, `kinozal`, нажмите *Create repository*.
   На странице репозитория нажмите *uploading an existing file* и перетащите туда **содержимое** распакованной папки
   (`server.js`, `package.json`, `package-lock.json`, `render.yaml`, `README.md` и папку `public`). Нажмите *Commit changes*.

2. **Создайте сервис на Render.**
   Зайдите на <https://dashboard.render.com>, войдите через GitHub.
   Нажмите *New* → *Web Service* → выберите репозиторий `kinozal`.
   Render сам подставит настройки; проверьте:
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**

   Нажмите *Deploy Web Service* и подождите 2–3 минуты.

3. **Готово.** Адрес будет вида `https://kinozal-xxxx.onrender.com`. Откройте его, создайте комнату, нажмите «Скопировать ссылку» и отправьте друзьям.

> На бесплатном тарифе Render «засыпает» после 15 минут без посетителей. Первое открытие после сна занимает около минуты, дальше всё работает быстро. Комнаты и чат хранятся в памяти и сбрасываются при перезапуске.

## Вариант 2. Запустить на своём компьютере и дать ссылку друзьям

1. Установите Node.js 18+ с <https://nodejs.org>.
2. В папке проекта выполните:
   ```
   npm install
   npm start
   ```
   Кинозал откроется на <http://localhost:3000>.
3. Чтобы друзья могли зайти из интернета, нужен https-адрес (без него браузер не даст микрофон).
   Проще всего — Cloudflare Tunnel, регистрация не нужна. Установите `cloudflared`
   (<https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/>) и запустите:
   ```
   cloudflared tunnel --url http://localhost:3000
   ```
   В выводе появится ссылка вида `https://случайные-слова.trycloudflare.com` — её и отправляйте.
   Работает, пока компьютер включён и окно с командой открыто.

## Что важно знать

**Ссылки на видео.** YouTube и Rutube вставляются обычной ссылкой на ролик (`youtube.com/watch?v=…`, `rutube.ru/video/…`, закрытые ролики Rutube — вместе с параметром `?p=…`). Для остальных сайтов нужна ссылка именно на видеофайл или поток (`.mp4`, `.webm`, `.m3u8`), а не на страницу с плеером. Платные ролики, ролики с ограничением по возрасту и те, что владельцы запретили встраивать, площадки не покажут.

**Одноклассники и VK Видео** не поддерживаются: их плеер нельзя ставить на паузу и перематывать со стороны, поэтому синхронизировать его невозможно. Обходной путь — скачать видео и открыть через «Свой файл».

**Vercel не подходит**: там нет постоянно работающего сервера, а он нужен для синхронизации, чата и голоса. Используйте Render, Railway, Fly.io или Koyeb.

**Свой файл.** Видео не загружается на сервер: каждый участник открывает у себя тот же файл кнопкой «Открыть файл». Так можно смотреть хоть в 4K без нагрузки на интернет. Формат должен поддерживаться браузером (`.mp4` с H.264/AAC открывается везде; `.mkv` — только в Chrome/Edge и не со всеми звуковыми дорожками).

**Голосовой чат** работает напрямую между участниками (каждый с каждым), комфортно до 5–6 человек. Чтобы не было эха, лучше сидеть в наушниках.
Если у кого-то голос не соединяется (обычно мобильный интернет или строгий роутер), нужен TURN-сервер.
Бесплатный вариант — Metered Open Relay (<https://www.metered.ca/tools/openrelay/>): после регистрации вы получите адрес, логин и пароль.
Добавьте их в Render → ваш сервис → *Environment*:

| Переменная        | Пример                                                    |
|-------------------|-----------------------------------------------------------|
| `TURN_URL`        | `turn:a.relay.metered.ca:80,turn:a.relay.metered.ca:443?transport=tcp` |
| `TURN_USERNAME`   | логин из кабинета                                          |
| `TURN_CREDENTIAL` | пароль из кабинета                                         |

**Звук при входе.** Браузеры не включают видео со звуком без клика. Если друг зашёл в уже идущий фильм, у него появится кнопка «Включить видео» — один клик, и он на нужной секунде.

## Устройство

- `server.js` — Express + Socket.IO: комнаты, состояние плеера (что идёт, играет ли, позиция и время изменения), чат, пересылка WebRTC-сигналов.
- `public/app.js` — клиент: плееры (HTML5, hls.js, YouTube IFrame API, Rutube Player API), сверка часов с сервером, плавная подстройка рассинхрона, чат, голос.
- `public/style.css`, `public/index.html` — интерфейс.
